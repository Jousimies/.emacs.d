#+TITLE: My Emacs Configuration

* Emacs 使用

首次使用，安装。
#+begin_src shell
  git clone --depth=1 https://github.com/Jousimies/.emacs.d.git
  cd .emacs.d
  python update_emacs.py setup
#+end_src

日常修改配置或 package 源码后，只需同步本地缓存与 byte-compile 产物：

#+begin_src shell
  python update_emacs.py
#+end_src

脚本的维护命令彼此独立，避免日常同步时隐式执行网络、原生构建或环境设置：

- =sync=（默认）：生成 load-path/autoload/idle-feature 缓存并 byte compile
- =fetch=：仅 fetch 主仓库与 submodule，不切换工作区版本
- =build=：仅构建 AUCTeX、benchmark-init 和 pdf-tools
- =setup=：首次安装流程（mail + fetch + build + sync）
- =doctor=、=env=、=test=、=clean=、=mail=：诊断与专项维护

** 维护脚本结构

=update_emacs.py= 只保留命令入口，具体实现位于 =core/=：

- =context.py=：路径、运行参数和进程调用
- =git.py=、=build.py=：源码获取与原生构建
- =build_tree.py=：维护用于加载和编译的 Elisp 镜像
- =autoload.py=、=idle.py=：生成 load-path/autoload 与 idle plan
- =cache.py=、=compiler.py=：协调缓存生成与 byte compile
- =mail.py=、=environment.py=：用户环境设置与安全快照
- =doctor.py=、=testing.py=、=cleanup.py=：诊断、测试与清理
- =cli.py=：参数解析和工作流组合

** 需特殊设置的 Packages

*** Benchmark-init
#+begin_src shell
  cd ~/.emacs.d/packages/benchmark-init-el/
  make
#+end_src

使用 --debug-init 参数启用 benchmark.

*** Auctex
#+begin_src shell
  cd ~/.emacs.d/packages/auctex/
  make
#+end_src

make 后会生成 auctex-autoloads.el, 在 Auctex 14 版本中加载此文件即可。

* Emacs 启动策略

1. 启动期 early-init + init
2. 包管理完成后 after-init-hook
3. 空闲增量 idle-timer 链式
4. 真正交互时 first-buffer / first-file / first-input
5. 命令触发 :commands / :bind / :hook

** 配置自检

- =M-x my/config-report=：查看模块加载状态/耗时、空闲加载队列、生成缓存和外部命令。
- =M-x my/config-retry-failed-modules=：修复问题后，只重试启动时失败的模块。
- 普通启动会隔离单个延迟模块的错误并继续；使用 =emacs --debug-init= 时仍会立即中断，便于定位。
- 项目根目录可通过 =M-x customize-variable RET my/project-folder= 调整；macOS/Linux 默认使用 =~/Repositories/=。
