#+TITLE: My Emacs Configuration

* Emacs 使用

首次使用，安装。
#+begin_src shell
  git clone --depth=1 https://github.com/Jousimies/.emacs.d.git

  git submodule update --init --recursive

  python update_emacs.py
#+end_src

** 需特殊设置的 Packages

*** Benchmark-init
#+begin_src shell
  cd ~/.emacs.d/packages/benchmark-init-el/
  make
#+end_src

使用 --debug-init 参数启用 benchmark.

*** Auctex
#+begin_src shell
  cd ~/.emacs.d/packages/auctex/
  make
#+end_src

make 后会生成 auctex-autoloads.el, 在 Auctex 14 版本中加载此文件即可。

* Emacs 启动策略

1. 启动期 early-init + init
2. 包管理完成后 after-init-hook
3. 空闲增量 idle-timer 链式
4. 真正交互时 first-buffer / first-file / first-input
5. 命令触发 :commands / :bind / :hook
